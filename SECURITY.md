# Security

Cockpit runs a local server that can read files you point it at and open programs on your PC, so security
problems matter even though it only listens on `127.0.0.1`.

If you find one (a way for a web page, another user, or a file you open to reach Cockpit's API, read your files, or
run something), please **don't open a public issue**. Report it privately through GitHub's
[security advisories](../../security/advisories/new) for this repository.

You'll get a reply within a week. Thank you.
